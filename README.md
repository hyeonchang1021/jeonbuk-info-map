## 검증 결과 — E(외부) / I(내부) 구분

**중요: 외부 검증(E)은 0건이다.**
아래는 전부 이 파일 안의 원본 배열을 다른 경로로 다시 계산한 **내부 검증(I)** 이다.
행정안전부·국토정보플랫폼 원본을 직접 내려받아 대조하지는 **않았다.**
따라서 *"이 파일이 원본을 정확히 옮겼는가"* 는 확인됐지만,
*"원본 자체가 맞는가"* 는 이 문서로 보증할 수 없다.

## 외부 의존과 폴백

| 자원 | 1순위 | 폴백 | 실측 검증 |
|---|---|---|---|
| Leaflet 1.9.4 | `vendor/leaflet.js` (로컬) | unpkg → jsdelivr → 안내 메시지 | **3단 전부 실측 확인** |
| 배경 지도 타일 | CARTO light_all | OpenTopoMap · Esri 2종 · OSM · CARTO dark (5종) + 실패 누적 시 1순위 복귀 | 1순위만 확인, 대안 5종 미확인 |

- Leaflet 로컬 번들에 **이미지 파일은 없다.** 이 페이지는 `L.circleMarker` 만 쓰고
  `L.marker` / `L.Icon` / `L.control.layers` 를 쓰지 않아 브라우저가 요청하지 않는다 (실측 확인).
- **타일은 외부 의존을 없앨 수 없다.** 오프라인·사내망에서는 배경 지도가 비고 경계·점·선만 보인다.
- 3곳 모두 실패하면 지도 영역에 사유가 표시된다. 이때 **좌측 패널도 함께 빈다** —
  본체 스크립트가 지도 생성 시점에 멈추기 때문이다 (차단 사본으로 실측 확인).

## 한계 — 이 결과를 무엇에 쓰면 안 되는가

1. **시설 수를 지역 간 비교 지표로 쓰면 안 된다.** OSM 등록분만 포함되어 실제보다 적다.
   예: 소방 관련 40건에 정읍·순창·진안 소방서가 빠져 있다.
2. **`hospital` 태그를 병원급으로 읽으면 안 된다.** 한국 OSM에서 의원급에도 쓰여 섞여 있다.
3. **도로 길이·거리를 측정하면 안 된다.** 형상이 정점 1/3 축약 근사다.
4. **표고·경사 분석에 쓰면 안 된다.** 지형·위성은 배경 타일이며 고도 수치 데이터가 아니다.
5. **용도지역이 비어 보이는 곳을 인구 0으로 읽으면 안 된다.** 도시지역만 덮어 인구의 80.7%다.
6. **읍면동 점을 인구 분포 중심으로 읽으면 안 된다.** 행정복지센터 위치 기준 대표점이다.
   243개 중 15개는 좌표 미확보로 지도에 없다 (인구 합계에는 포함).
7. **단계구분 구간은 2024-10 기준으로 산정된 값을 2026-06 인구에 적용했다.** 구간 자체는 갱신되지 않았다.
8. **경계 좌표는 자체 역투영 결과다.** 원본 EPSG:5179를 WGS84로 변환했으며, 공식 WGS84 성과와 대조하지 않았다.
9. **기준 시점이 섞여 있다.** 경계·용도지역 2024-10 + 인구 2026-06 + OSM 수집분.
   같은 시점 자료로 맞춰야 하는 분석에는 쓸 수 없다.
10. **브라우저 1종에서만 확인했다.** Safari·iOS 실기기에서는 검증하지 않았다.

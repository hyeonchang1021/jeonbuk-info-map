# 상황 회화 미션

상대가 영어로 말을 걸면(사람 목소리 녹음), 학생이 상황에 맞게 자기 말로 자유롭게 대답하는 말하기 연습입니다.
학생이 손님인 미션 24개(직원이 말을 걺)와 학생이 직원(마트 캐셔·서버·옷 가게 점원)인 미션 24개, 모두 대화 96번.

- 주소: https://hyeonchang1021.github.io/jeonbuk-info-map/english-speaking-mission/
- 평가(AI 없이 브라우저에서 계산): 내용 40%(할 일에 적힌 내용을 말했는지, 표현은 달라도 인정) + 말한 양 20% + 유창성 20%(말하기 속도·1.5초 넘는 멈춤) + 명료도 20%(인식 확신도). 내용을 빠뜨리면 상한(30 + 내용×0.7, 절반만 말하면 최대 65점). 70점 이상 통과.
- 대답 뒤에는 모범 답안을 듣고 따라 말하며 발음 점수(발음 연습과 같은 엄격 채점)를 받습니다.
- 결과(학생이 한 말을 글자로, 세부 점수, 빠뜨린 내용)는 선생님 관리 화면에 '회화' 단계로 기록되고, 선생님이 기록마다 메모를 남길 수 있습니다. 녹음 파일은 보내지 않습니다.
- 음성 인식은 Chrome·Edge·Safari에서 동작합니다. Chrome은 인식을 위해 음성을 Google 서버로 보냅니다.
- 목소리: 대사와 모범 답안은 공개 음성 합성 모델 Kokoro(Apache-2.0)로 미리 녹음한 mp3(audio/)를 틉니다. 미션마다 상대 목소리가 다릅니다. 파일을 못 틀면 브라우저 음성으로 대신합니다.

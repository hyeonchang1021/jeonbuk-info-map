# 고급 영단어 500 퀴즈

영어 단어를 보고 알맞은 한글 뜻을 다섯 개 중에서 고르는 퀴즈의 고급편.
기초(`../english-500-quiz/`)·중급(`../english-intermediate-quiz/`)과 겹치지 않는 500개를 20개 주제로 묶었다.
회의·경제·법·뉴스 어휘와 고급 구동사, 관용 표현, 캐나다 구어가 들어 있다.

**라이브: <https://hyeonchang1021.github.io/jeonbuk-info-map/english-advanced-quiz/>**

지도 본체와는 별개의 페이지다. `index.html` 한 파일로 동작하며, 글꼴만 Google Fonts에서 불러온다(못 불러오면 기기 기본 글꼴로 보인다).

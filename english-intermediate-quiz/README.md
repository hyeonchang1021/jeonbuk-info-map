# 중급 영단어 500 퀴즈

영어 단어를 보고 알맞은 한글 뜻을 다섯 개 중에서 고르는 퀴즈의 중급편.
기초 500단어(`../english-500-quiz/`)와 겹치지 않는 단어 500개를 20개 주제로 묶었다.
집 계약·금융·행정·직장에서 쓰는 단어와 구동사 50개가 들어 있다.

**라이브: <https://hyeonchang1021.github.io/jeonbuk-info-map/english-intermediate-quiz/>**

지도 본체와는 별개의 페이지다. `index.html` 한 파일로 동작하며, 글꼴만 Google Fonts에서 불러온다(못 불러오면 기기 기본 글꼴로 보인다).
